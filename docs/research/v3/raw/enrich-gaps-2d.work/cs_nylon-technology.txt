Table of contents Heading 2 The Challenge Nylon Technology is a web development agency that has been in business since 1997 and specializes in web-based software projects including custom website, intranet, extranet, RIA, content management and database solutions. After trying several other online timesheet systems, they switched to ClickTime over a year ago and have been very happy with the service. In order to better manage and report on the efficiency and profitability of their projects and staff, they identified the need to integrate their timesheet data with some of their internal applications. Nylon Technology has a long history with ColdFusion, the application development platform, and needed to get the integration up and running as quickly as possible, so they wrote a complete localized business logic tier and an accompanying data storage interface to ClickTime using the ClickTime Web Services API and ColdFusion . This tier enabled them to synchronize data with the hosted ClickTime environment and use the ClickTime data within their internal applications and processes. They’re now exploring further integration solutions with ClickTime including custom reporting, payroll, Subversion source control, and Exchange Server. According to Simon Horwith, the Chief Technology Officer for Nylon Technology, “the ClickTime API is fairly robust and was easy to work with. Now we have all of our up-to-date ClickTime data at our fingertips in a local SQL Server Database for use however we need. The ColdFusion client tier we wrote allows us to work with ‘live’ data via the API or the already captured local data interchangeably and seamlessly, and it has been written in such a way that we can quickly offer the same ClickTime integration to any project for our clients who also use ClickTime.” “Though we used ColdFusion for our internal integration tier, Nylon Technology is also very experienced delivering projects for mobile devices and has in-house expertise and experience with PHP, Flex/Flash, Python, Java, and .NET. We are always excited to help new clients find better ways to use technology.” Adriana Baranetki Share Copied!
